java = 객체 지향적 프로그래밍 언어

java 자료형은 크게 primitive type 기본자료형/reference type 참조자료형/ 으로 구분

primitive type
short/int/long/float/double/char/boolean/byte 등이 있다
short/int/long은 숫자형으로 나타낼 수 있는 숫자의 크기가 다름 이는 각 타입에 할당되는 메모리의 크기가 다르기 떄문
순서대로 각 2 바이트, 4 바이트, 8바이트 가 할당 가능 

reference type
참조 자료형은 기본 자료형을 제외한 모든 자료형을 말한다 자바의 인스턴스를 가리킬 수 있는 자료형이다 클래스, 배열, 열거, 인터페이스 등이 존재한다.
가장 친근한 string 또한 참조 자료형에 손한다 (클래스)

배열 (array)

배열 변수명 선언 (arr이 배열의 변수 명)

int arr[];

배열 생성 (이때 크기 지정도 같이함)

arr = new int[5]

초기화 (생성된 배열에 값을 넣어준다)

배열은 선언과 동시에 크기를 지정받는다 따라서 고정된 크기를 갖는다
하지만 실제로 고정된 크기의 배열만을 쓰기는 쉽지 않음 때문에 보통 배열보다는 arraylist 라는 collection 을 사용함
